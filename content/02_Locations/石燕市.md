# 石燕市

## 概要

[[神津市]]の南側に位置する工業・港湾都市。沿岸部にはもともと小規模な漁村が点在していたが、文明開化以後に重工業が発達し、明治・大正期には大型工場とその周辺住宅地が形成された。大型船舶に対応する造船・港湾機能も神津側から移り、昭和期には重工業・港湾物流を担う一大生産拠点へ発展した。

現代では、[[神津市]]が経済・商業の中心、石燕市が工業生産・物流の中心という役割分担がある。[[三神工業]]等で研究・開発された技術の量産拠点としても重要である。

沿岸部は山地が海岸近くまで迫る地形で、山と海の間に広い平地がある区間には工場・港湾施設が発達し、平地の狭い区間には旧来の漁村が残る。工業都市化後も複数の漁村・漁港が沿岸に点在する。

明治・大正頃までは、石燕の海産物や工業技術が[[辻切区]]へ集まり、[[神津市]]内や[[三春夜市]]方面へつながる交易路が形成されていた。各都市が独自に発展した現代も、この経路は販路として強い。

## 地理

### 位置

[[神津市]]の南側に位置する。[[高天山脈]]では[[高天町]]と接し、[[高天リゾート]]のゲレンデ降り口と、その降り口側の関連施設を含む。

沿岸部では山地が海岸近くまで迫り、海岸と山地との間の平地幅が場所によって大きく異なる。

### 地形・標高

沿岸から山地までの距離が短い地域が多い。平地の広い区間は工業・港湾利用が進み、狭い区間には旧漁村が残る。

山地の高台には、大砲製造に用いられた反射炉がある。高台から[[神津湾]]を望むことができ、展望拠点としても利用されてきた。

### 水系

石燕市側の港はもともと水深があり、浚渫もしやすい。[[神津湾]]の水深では対応できない喫水の深い大型船舶は、石燕市側の港を利用する。

### 土地利用

旧来の漁村群の近隣に明治・大正期の大型工場が建設され、工場労働者等の住宅地が周囲へ拡大した。

沿岸部では、山と海の間に十分な平地がある場所に大型工場、造船・港湾施設、物流施設などが集中する。一方、山が海岸近くまで迫る場所では大規模開発が入りにくく、旧来の漁村が残る。このため、工業地帯と漁村が沿岸に交互に現れる地域がある。

比較的大きな漁村・漁港の一部は遠洋漁業の基地として機能する。

現代は大型船に対応する港湾、造船・重工業施設、物流施設、住宅地によって市街地が形成されているが、それぞれの正確な境界と下位区画名は未定。

県内の航空玄関口である[[神白空港]]があり、石燕市の大規模物流機能の一部を担う。

### 景観

巨大工場、造船・港湾設備、クレーン、工業港の夜景と、山際に残る旧漁村の景観が混在する。

山地の反射炉周辺からは[[神津湾]]方面を見渡せる。

## 沿革

| 時期 | 出来事 |
|---|---|
| 古く | 沿岸部に小規模な漁村が点在する。 |
| 近代化以前 | 山地の高台に反射炉が設けられ、大砲製造に用いられる。反射炉周辺は神津湾を望む高所でもあり、展望・監視に適した場所であった。 |
| 明治・大正期 | 文明開化以後、漁村の近隣に大型工場が建設され、住宅地が形成される。大型船舶に対応する造船・港湾機能が神津側から石燕へ移る。神亜財閥を中心に、独立性の強い関連企業が緊密に協業する企業連合的な工業体制が発達する。 |
| 戦時期 | 戦時体制下で、石燕の工業地域の土地・施設が国によって買収され、軍需工場として利用される。[[神亜重工]]は買収によって得た資金を用い、現在の[[三神工業]]にあたる地域へ研究所を設ける。これが後の三神工業地帯の基礎となる。 |
| 戦争末期 | 軍需工場となっていた工業地域一帯が焼夷弾による空襲を受け、広範囲が焼失する。 |
| 戦後 | 旧工業地域の国有地・施設について払い下げを受け、焼け野原となった地域に工場群を再建する。石燕は大規模な生産拠点として再編される。財閥解体後、神亜財閥の協業関係は神亜グループとして引き継がれる。 |
| 昭和期 | 神津湾より水深があり浚渫しやすい港を背景に、重化学工業と物流を中心とする都市へ発展する。一時期は工業地域周辺の環境汚染が深刻化するが、全国的に公害問題が大きくなる以前から環境保全・改善へ着手し、早期に改善局面へ入る。 |
| 現代 | 神亜グループをはじめとする企業群の協業文化は維持され、[[三神工業]]の共同研究・開発体制にも受け継がれる。石燕市は研究開発された技術を量産する大規模生産・物流拠点として機能する。 |

## 都市機能

### 行政・公共


### 産業・商業

造船、重工業、港湾物流が主要産業。[[三神工業]]等で開発された技術を量産する神津関連企業の工場も多い。

アルミニウム等の素材産業がある。港湾物流と大規模な電力需要を背景とする産業だが、一次精錬まで市内で行うか、加工を中心とするかは未定である。

[[神亜重工]]は石燕市に本社を置き、石燕の工業発展を長く主導してきた。戦前は神亜財閥を中心として、各企業が独立性を保ちながら強く連帯し、共同で事業を進める企業連合的な性格を持っていた。財閥解体後は神亜グループとして協業関係が継続し、その文化は現代の[[三神工業]]にもつながっている。

港湾は天然に比較的深く、浚渫にも適する。[[神津湾]]の浅い港では対応できない喫水の深い大型船舶は石燕市側の港を利用する。

沿岸の比較的大きな漁村・漁港では遠洋漁業も行われる。

エネルギー供給は、過去には港から燃料を搬入する石炭火力と、山地を利用した水力が用いられた。現代は環境負荷の低減を重視し、地熱、洋上風力、海洋深層水の冷熱、工場廃熱、水力を組み合わせて利用する。これらの事業には[[神亜エコロジカルエナジーパートナー]]が関わる。

市域には地熱活動と温泉があり、地熱は発電だけでなく、工場や地域への熱供給、温水、冷熱にも複合的に利用される。温泉を利用した施設も存在する。

### 交通

[[辻切区]]南部からトンネルで接続し、工業製品や港湾貨物のトラック輸送が多い。歴史的には石燕の海産物や工業技術を辻切へ運ぶ交易路であり、現代も神津・辻切方面への主要な販路となっている。

[[神津市]]の[[港湾区]]から続く湾岸道路がある。

[[高天リゾート]]では、石燕市側のゲレンデ降り口と関連施設から[[高天町]]側と往来できる。石燕市側の施設は高天町側と同じ経営母体によって運営される。

[[神白空港]]は、軽量・高価・精密・緊急性の高い貨物の航空輸送に利用される。大量貨物を担う大型船、鉄道・トラックによる陸上輸送と役割を分け、[[三神工業]]の試作品、精密機器、医療・研究機材等を扱う。

### 教育・研究

先端研究・開発の主要拠点は[[三神工業]]側にあり、石燕市はその成果を工業生産・量産へ移す役割が強い。

### 地域性

点在していた小規模な漁村群を起点として、大型工場、住宅地、港湾物流機能が段階的に加わった工業都市である。工業地帯と旧漁村が海岸線に混在し、山地の反射炉から近現代の重工業、現代の先端技術量産まで、異なる時代の工業史が重なっている。

企業間の連帯と協業が強く、神亜財閥から神亜グループ、さらに[[三神工業]]へと、組織形態を変えながら共同開発・共同事業の文化が継続している。

## 裏設定

- [[神亜重工]]は、神凪氏の一派と鍛冶の鬼の家が主導する企業である。古くから最先端技術を担い、神凪の神の庭を汚染しないことが企業活動の根底にある。この背景が、表向きにも早期の環境保全・公害対策として現れている。
- 神亜系企業群の強い協業文化には、神凪の神の庭に共通する連帯性が関係している。
- 石燕市の湾岸工場地帯から[[辻切区]]南西部の物流区画まで地下の専用物流道が延び、辻切側には地上・地下の巨大物流倉庫がある。この物流系統では無人リニアの実証実験も行われている。一般の鉄道路線としては扱われない。新谷坂温泉郷・間欠泉地帯からは少し離れたルートを通る。
- 地下物流道を将来は神津方面まで延伸する構想があるが、神津側には旧湿地・軟弱地盤が多く、終端や物流ターミナルの設置が難しい。
